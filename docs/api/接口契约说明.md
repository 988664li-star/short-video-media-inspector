# API 契约说明

## 唯一事实来源

[开放接口规范V1.yaml](./开放接口规范V1.yaml) 是第一阶段新增业务接口的唯一契约来源。前端请求封装、FastAPI 路由、Pydantic Schema、Mock 和契约测试都必须与它保持一致。

## 变更规则

1. 先修改 OpenAPI，再修改前端和后端实现。
2. 已发布字段只允许新增可选字段；删除或改变语义必须创建 `/api/v2`。
3. 创建任务、订单、取消任务等写操作必须声明 `Idempotency-Key`。
4. 长任务只能返回 `202 + job_id`，结果通过查询接口或 SSE/WebSocket 获得。
5. 所有错误返回统一 `error.code`、`error.message`、`request_id`。
6. 支付 Webhook 根据微信支付/支付宝各自规范实现，但内部订单状态和幂等语义必须遵循本契约。

## 实现顺序

先实现 `Auth → Uploads → Projects → Jobs → Billing → Notifications`。每完成一个 tag，即增加 FastAPI 路由测试和 OpenAPI 契约测试。
